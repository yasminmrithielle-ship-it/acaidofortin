# Açaí do Fortin - Web App Instalável

Esta pasta é a versão PWA do app. Para instalar no smartphone, publique estes arquivos em um domínio com HTTPS e abra o site pelo navegador do celular.

## Como instalar no Android

1. Abra o link HTTPS no Google Chrome.
2. Toque no botão `Instalar app`, se aparecer.
3. Se o botão não aparecer, abra o menu do Chrome e toque em `Instalar app` ou `Adicionar à tela inicial`.

## Como instalar no iPhone

1. Abra o link HTTPS no Safari.
2. Toque no botão de compartilhar.
3. Toque em `Adicionar à Tela de Início`.

## Arquivos principais

- `index.html`: app completo.
- `manifest.webmanifest`: configuração de instalação.
- `sw.js`: cache offline e carregamento rápido.
- `assets/icons`: ícones usados pelo Android e iOS.
